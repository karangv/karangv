## 💻 Featured Projects
- 🎬 **[YouTube Movie Ratings](https://github.com/karangv/youtube-movie-ratings)** - a Chrome extension that shows IMDb, Rotten Tomatoes, and Metacritic ratings directly on YouTube movie pages, with a personalized movie recommender (TypeScript, React, WXT)
- 🔊 **[Audio Prompt Injection Attacks on LLMs](https://github.com/karangv/audio-prompt-injection-LLMs)** - adversarial audio attacks on large audio-language models, with Gaussian-noise augmentation and an LLM-as-judge evaluation pipeline (Python)
- 💳 **[Credit Card Fraud Detection](https://github.com/karangv/fraud-detection-ml)** - an end-to-end XGBoost pipeline for fraud detection on a 577:1 imbalanced dataset, with SMOTE and a decision threshold tuned against a business cost matrix (Python, scikit-learn)
